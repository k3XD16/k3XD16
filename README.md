## 👋 About Me

I'm a data engineer based in Chennai, India, building pipelines and analytics that connect technical work to business questions. My projects span event streaming, cloud lakehouses, dimensional modeling, and interactive BI dashboards. I start with the decision a team needs to make, then work backward to the metrics, data models, and reliable pipelines that support it.
